## 📌 Overview

**Exact Bytes** is a fast, lightweight, privacy-focused utility tool designed to solve a common, frustrating problem: **getting rejected by portal file upload limits**. 

Whether you are applying for competitive exams (UPSC, SSC, NEET, JEE), uploading documents to job portals, or filling out government forms, online systems often require strict file sizes (e.g., *"Signature must be between 10KB and 20KB"*). Exact Bytes takes the guesswork out of image and PDF compression by hitting your exact KB target without destroying image quality.

---

## ✨ Key Features

- 🎯 **Targeted KB Compression:** Set your exact maximum file size limit (e.g., `50 KB`, `200 KB`) and let the algorithm automatically calibrate quality and scale.
- 🖼️ **Multi-Format Support:** Easily process **JPEG**, **PNG**, **WEBP**, and **PDF** files.
- ✍️ **Signature & Photo Presets:** Pre-configured shortcuts for popular exam standards, passport dimensions, and signature sizes.
- 📐 **DPI & Dimension Control:** Fine-tune resolution (72, 150, 300 DPI) and image dimensions while maintaining target KB limits.
- 🔒 **100% Client-Side Privacy:** Your files **never leave your device**. All processing happens directly in your browser using local APIs. No data is stored or transmitted.
- ⚡ **Lightning Fast:** Zero server wait times—instant live previews and instant downloads.

## 🏃 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16 or higher) and `npm` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/exact-bytes.git
   cd exact-bytes
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🛡️ Privacy & Security

Security and user privacy are foundational principles of Exact Bytes:
- **Zero Server Uploads:** All compression algorithms execute inside the client's web browser context.
- **Zero Data Collection:** We do not track, log, or store your uploaded files, images, or metadata.
